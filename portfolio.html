02 / ORACLE-DIT In production

Oracle DIT Tools

Codex-native AI operations platform

An AI operations layer, not a chatbot wrapper. It lets an agent (Codex) turn requests like "is DITA up?", "reserve a DIT", or "run VM.Check-config" into approved internal Oracle operations. A thin Codex plugin talks to a Python MCP server that exposes business-level tools, maps them to allowlisted Jenkins jobs, and returns clean results. I designed it to be safe by construction: signed stateless status handles for async jobs, credential redaction, owner-scoped polling, and separate DIT/VM controllers — all covered by unit and evaluator tests.

04 / POKER-AI Complete

Poker AI

Texas Hold'em agent · CSC 480

A Texas Hold'em bot built on pypokerengine that reasons under uncertainty. A Monte Carlo engine estimates win probability from thousands of simulated rollouts, an opponent-modeling layer tracks how each player behaves over time, and a pot-odds module ties it into disciplined betting decisions. I built a benchmark suite that pits agent variants against each other to measure exactly how much each feature adds — plus a pygame UI so you can sit down and play against it.

06 / FOCUS-DAY Live demo

Focus Day

A planner built for a distractible brain

Traditional to-do apps made focus harder for me — endless backlogs, notifications, and guilt over unfinished lists. Focus Day takes the opposite approach: instead of an infinite list, it forces a small, prioritized plan for today, color-coded by urgency in a calm interface designed to reduce overwhelm. It even includes a voice mode — describe your day out loud and it parses your words into scheduled tasks. What started as a personal fix is becoming a genuine productivity tool for students who think the way I do. Try the live demo →
